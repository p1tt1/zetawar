# Zetawar Project Documentation

This folder contains comprehensive documentation for the Zetawar project, a turn-based strategy game and AI platform built with ClojureScript.

## Documentation Structure

The documentation is organized into several markdown files, each focusing on a specific aspect of the project:

1. [**Overview**](01-overview.md) - A high-level introduction to the project, its structure, and key components.

2. [**Architecture and Paradigms**](02-architecture-and-paradigms.md) - Detailed explanation of the architectural patterns and programming paradigms used in the project.

3. [**Data Model**](03-data-model.md) - Description of the DataScript schema and how the game state is structured and managed.

4. [**Game Mechanics**](04-game-mechanics.md) - Explanation of the core game mechanics, including turns, unit actions, combat, and win conditions.

5. [**UI Components**](05-ui-components.md) - Overview of the UI components, rendering process, and how the UI interacts with the game state.

6. [**AI System**](06-ai-system.md) - Details about the AI system, different AI implementations, and how they make decisions.

7. [**Dependencies**](07-dependencies.md) - List of dependencies used in the project, their purposes, and how they are integrated.

8. [**Conclusion**](08-conclusion.md) - Summary of the key aspects of the project and guidance for further exploration.

## How to Use This Documentation

- **New to the Project**: Start with the [Overview](01-overview.md) to get a high-level understanding of the project, then proceed through the documents in order.

- **Looking for Specific Information**: Use the links above to jump directly to the relevant document.

- **Developers**: The documentation includes code examples and references to specific files in the project, which can help you understand how different parts of the codebase work together.
